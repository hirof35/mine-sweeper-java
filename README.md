# Minesweeper Pro (Java Swing)

Java Swingを用いて開発された、古典的なマインスイーパーの高度なクローンです。単なるゲームの実装にとどまらず、ユーザー体験を損なわないためのアルゴリズムの最適化と、永続的なデータ管理（ベストスコア保存）を実装しています。

## 概要
本作は、Windows標準のマインスイーパーの挙動を忠実に再現しつつ、エンジニアリングの観点から「初手での理不尽なゲームオーバー」を排除するロジックを組み込んだ、信頼性の高いゲームシステムです。

## 主な機能と技術的特徴
*   **初手セーフ・アルゴリズム (First-Click Safety)**:
    最初のクリックが行われた瞬間に地雷を配置する「遅延生成」を採用。初手とその周辺8マスには絶対に地雷が配置されない構造になっており、運要素を排除した戦略的なゲームプレイを保証します。
*   **効率的なリソース管理**:
    難易度変更時以外はGUIコンポーネント（JButton）を再生成せず、状態のみをリセットする設計により、メモリ消費と描画負荷を最小限に抑えています。
*   **再帰的なタイル開放**:
    地雷が隣接していないセルをクリックした際、周囲の空白地帯を瞬時に開放する再帰アルゴリズムを最適化して実装しています。
*   **永続的なスコア記録**:
    `java.util.prefs.Preferences` APIを利用し、OSのレジストリや設定ファイルに難易度別のベストスコア（最短クリアタイム）を保存します。
*   **インタラクティブなUIフィードバック**:
    ニコちゃんマーク（リセットボタン）の状態変化や、ゲームオーバー時の地雷連鎖爆発アニメーションなど、視覚的なフィードバックにこだわっています。

## 操作方法
| 操作 | アクション |
| :--- | :--- |
| **左クリック** | セルを開く（初手は必ず安全） |
| **右クリック** | フラグ（🚩）の設置 / 解除 |
| **中央ボタン (🙂)** | ゲームのリセット（現在の難易度で再開） |
| **メニューバー** | 難易度（初級・中級・上級）の切り替え |

## システム構成
*   **開発言語**: Java 8以上
*   **フレームワーク**: Java Swing (GUI)
*   **データ保存**: Java Preferences API

## 導入・実行手順
1.  **コンパイル**
    ```bash
    javac minesweeper/Minesweeper.java
    ```
2.  **実行**
    ```bash
    java minesweeper.Minesweeper
    ```
